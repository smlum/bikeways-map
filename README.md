# bikeways-map

Web map for validating the Canadian Cycling Network Database (CCND) against lived experience.

## Data

- CCND 2024 — Statistics Canada
- Can-BICS OpenStreetMap 2024 and 2026 — Can-BICS national data (ODbL)
- 2021 census subdivision boundaries — Statistics Canada

## Setup

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Pipeline

```sh
python -m pipeline.run                    # all sources, all steps
python -m pipeline.run ccnd_2024 --steps prepare summaries
```

Preview locally (needs Range support for PMTiles):

```sh
python scripts/serve.py   # http://localhost:8000
```

Config lives in `config/`: sources, classes, places (name mapping + CSD profile areas), comparisons (dataset pairs to match), scope, tile and web settings.
New source or vintage: add to `sources.yaml`, then `python scripts/seed_places.py <source_id>` and review `places.yaml`.

## Known issues

Data issues live in `config/issues.yaml` and show in the map's Issues panel (right), usually one per
place and class pair (e.g. CCND bike path that should be multi-use path) with clicked segments as examples.

- **From the map:** click a segment, then **Add issue**; the form is prefilled from what you clicked.
  Saving needs the local server run from the venv (`python scripts/serve.py`), which writes straight to
  `config/issues.yaml`. Re-run `python -m pipeline.run --steps export` to bake them into the static site.
- **By hand:** edit `config/issues.yaml` (fields documented at the top).
- **From a form:** collect responses in a spreadsheet (`report_url` in `web.yaml` adds a link), mark rows
  approved, then `python scripts/import_issues.py responses.csv` (`--dry-run` to preview).

## Structure

```
data/raw/<dataset>/<vintage>/   source downloads (gitignored)
data/build/                     processed outputs / PMTiles
config/                         YAML config
pipeline/                       data prep (prepare → tiles → summaries → compare → export)
web/                            MapLibre app (web/data/ generated by pipeline)
scripts/                        dev utilities
```
